# Сниффер обмена ИОН ↔ ЭБУ (K-Line)

Снимает реальный обмен программы **ИОН (InjOnl.exe)** с ЭБУ Январь 5.1.61 по
K-Line — чтобы увидеть **точные команды и адреса**, которые ИОН читает
(в частности, откуда берёт абсолютное давление, тайминги, пачки чтения).

## Зачем так, а не сниф по проводу

K-Line однопроводная, но на линии одновременно может висеть только один
активный тестер: адаптер ИОН **или** ESP32, но не оба. Поэтому пассивно
слушать проводом нельзя. Вместо этого перехватываем у самого процесса ИОН
вызовы WinAPI работы с COM-портом через **Frida** — ИОН при этом работает
как обычно на своём COM1, ничего переставлять не нужно.

Снимаем: TX/RX байты с таймингами, смену скорости (`SetCommState`),
Read/Write таймауты (`SetCommTimeouts`), overlapped-чтения.

## Установка (один раз)

```
python -m pip install frida frida-tools
```

(нужен обычный Python; проверено на 3.13.)

## Запуск

Из корня репозитория:

```
python tools/ion-sniffer/sniff_ion.py
```

или

```
powershell -ExecutionPolicy Bypass -File tools\ion-sniffer\sniff.ps1
```

Что произойдёт:

1. Скрипт **сам запустит ИОН** и прицепится с первого байта.
2. В открывшемся окне ИОН нажми **«Подключить»** как обычно (COM1, 38400 —
   уже стоят в InjOnl.ini).
3. В консоли пойдёт живой обмен; он же пишется в файл
   `tools/ion-sniffer/ion_sniff_<дата>.log`.
4. **Ctrl+C** — остановить. Пришли мне лог-файл.

### Если ИОН уже открыт / spawn не сработал

Запусти ИОН руками, подключись, затем:

```
python tools/ion-sniffer/sniff_ion.py --attach
```

### Другой путь к ИОН

```
python tools/ion-sniffer/sniff_ion.py --exe "D:\path\to\InjOnl.exe"
```

## Формат лога

```
    <сек> +<пауза,мс>  <напр>[<n>]  <hex-байты>  <разбор кадра>
```

Пример того, что ищем (адрес чтения давления):

```
   12.345 +48    TX[ 6]  82 10 F1 21 01 A5            -> SID 21 ReadDataByLocalId  LID=0x01
   12.360 +15    RX[47]  ...                           <- SID 61 ...
   12.408 +48    TX[ 8]  23 00 F9 A0 02 ...            -> SID 23 ReadMemoryByAddress  addr=0xF9A0 len=2
```

`->` = запрос (тестер→ЭБУ), `<-` = ответ (ЭБУ→тестер). Разбор — best-effort
по ISO 14230/KWP; если ИОН шлёт проприетарный OLT-кадр, сырой hex всё равно
виден полностью.

## Файлы

- `sniff_ion.js` — Frida-инструментация (хуки WinAPI).
- `sniff_ion.py` — драйвер: запуск/attach, приём событий, разбор, лог.
- `sniff.ps1` — обёртка для запуска одной командой.
